## v0.1.0

Initial ADF template with four repository-local Codex Skills, optional native
Worker, local and GitHub tracking, durable execution state, and background jobs.
Adds read-only setup diagnostics, label planning, versioned Copier updates,
and patch generation for downstream contributions. Auto-resume defaults to
disabled. See [verification](verification.md) for environment-specific checks.
